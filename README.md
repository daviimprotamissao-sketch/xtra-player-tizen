# xTra Player — Samsung Tizen

Aplicativo de TV Samsung baseado em HTML, CSS e JavaScript, com interface adaptada para controle remoto.

## Compatibilidade planejada

- Samsung Smart TVs com Tizen 5.5 ou superior (a partir de modelos de 2020, sujeito à validação por modelo).
- Reprodução com Samsung AVPlay.
- Navegação por controle remoto.

## Estado do projeto

Este repositório está sendo iniciado. A implementação será feita por etapas: interface para TV, autenticação e sincronização Firebase, carregamento de playlists M3U/Xtream, catálogo separado em TV ao vivo/filmes/séries e reprodução AVPlay.

A criação de um arquivo `.wgt` não significa que ele esteja assinado ou pronto para instalação. A instalação em uma TV real exige empacotamento e assinatura com certificado Samsung/Tizen compatível.

## Segurança

Não coloque chaves privadas, certificados ou senhas no repositório. A configuração Firebase Web é pública por natureza; a segurança deve ser aplicada nas regras do Firebase e na autenticação.
